# 照片转油画棒 Skill 使用指南

这个 Skill 的使用门槛应该只有一个：**上传一张照片，并说你想得到什么。** 不需要自己编写提示词，也不需要提前知道油画棒风格名称。

## 最简单的用法

上传照片后发送：

> 把这张照片转成真实可画的油画棒作品，风格你帮我选。

Skill 会先用简短语言告诉你：哪些内容会保留、哪些会简化、为什么选择这种风格，然后默认生成一张静态成品。

## 想生成绘画过程

上传照片后发送：

> 把这张照片转成油画棒作品，再生成一个从铺色到完成的 6 秒循环 GIF。

可以把 `6 秒` 改为 5–10 秒。没有指定时长时默认 6 秒。过程动画是根据铺色、细化和定稿三个绘画阶段重新演绎，不是真人录像，也不是模型隐藏生成过程的录屏。

## 想控制画面感觉

不必说专业术语，直接描述感受即可：

- “颜色柔和一点，像安静的纪念画。”
- “保留人物和姿势，背景尽量简单。”
- “不要太精细，要像真的用油画棒手绘。”
- “纸张多露一点，笔触粗一些。”
- “主体必须和原照片一样，眼睛、鼻子和嘴不要变。”

Skill 会把这些自然语言转成风格卡和特征锁定规则。

## 带参考图或参考链接

可以同时提供照片和参考图，也可以给出能够访问的参考页面：

> 参考这个链接里的油画棒感觉，但不要照搬具体作品。请分析笔触、配色和留白，再为我的照片选择最合适的组合。

Skill 应提取可观察特征，例如笔触方向、覆盖密度、纸张底色、边缘软硬和颜色范围，而不是只写作者名字或生硬复制某一幅画。

## 三种推荐调用方式

### 1. 自动推荐

> 使用 photo-to-oil-pastel 处理这张照片，风格由你选择，只生成静态图。

### 2. 指定情绪

> 使用 photo-to-oil-pastel 把这张照片画成温暖、朴拙、留纸较多的油画棒作品，必须保留人物神态。

### 3. 静态图加过程动画

> 使用 photo-to-oil-pastel 先生成最终油画棒作品，再生成 6 秒步骤 GIF。每一阶段的主体结构和五官必须一致。

如果所在平台支持 `$技能名` 调用，也可以把上面的 `photo-to-oil-pastel` 写成 `$photo-to-oil-pastel`。其他平台使用各自的 Skill、工作流或 Agent 调用方式即可，核心自然语言不变。

## 正常的首次回复应该是什么样

收到照片后，助手不应该先抛出一长串问题，而应先给出类似下面的创作说明：

```text
保留：人物姿势、主要轮廓和光线方向。
简化：背景杂物、可读文字和照片级纹理。
风格：采用柔和叠色与局部干笔，保留明显纸张纹理。
交付：先生成静态成品。
```

只有当照片里有多个可能的主体，或者两种风格会导致明显不同的结果时，助手才应追问一个关键问题。

## 收到结果后怎么继续

可以直接说：

- “主体很好，背景再简单一点。”
- “换成更浓郁、更厚重的颜色。”
- “保留现在的定稿，继续做 6 秒 GIF。”
- “对比原图，检查人物五官有没有变化。”

每轮最多进行一次针对明确问题的生成纠正，避免无目标地反复重绘。
